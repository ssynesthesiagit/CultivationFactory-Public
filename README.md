# CultivationFactory public candidate

CultivationFactory is a local-first factory and combat prototype. This branch
is a clean-history, private draft candidate prepared for owner review. It is
not public, released, or approved for redistribution.

The application can run from the checked-in runtime authority bundle and uses
deterministic catalog/build inputs. The five legacy combat PNGs whose
provenance could not be positively verified remain excluded; combat rendering
uses an accessible CSS grid and generated-initials fallback until an artwork
rights decision is recorded.
