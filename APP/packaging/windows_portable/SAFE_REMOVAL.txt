Tianxia Current Owner Test — safe removal

1. Close the Tianxia Current Owner Test application.
2. Delete only the desktop shortcut named "Tianxia Current Owner Test".
3. Delete only the isolated Tianxia_Current_Owner_Test staging folder.

The staged application's data is confined to its OwnerTestData folder. Do not
delete or change any existing Tianxia Factory installation or production
UserData folder.
