# Public-candidate working rules

- Keep this repository publication-safe and independent of the private historical archive.
- Do not add credentials, personal data, retained `UserData`, owner-test evidence, private coordination, or downloaded artifacts.
- Treat Tianxia rules, setting text, catalogues, and game data as owner copyright-controlled unless a file states another license.
- Preserve the source-backed Background-Origin Insight classification in generated authority and catalog records; do not recategorize it as copied third-party content without new evidence.
- Keep combat artwork absent unless provenance and public-use permission are positively verified. The current UI must continue to work with its CSS-grid and initials fallback.
- Do not trigger GitHub Actions, merge pull requests, change repository visibility, or copy history from the private repository.
- Run local, deterministic checks before updating the draft PR. Never include secret values in reports.
